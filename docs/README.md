# 4less

Minimal DSL that compiles to HTML, React, Vue, and Astro. Zero dependencies.

## Install

```bash
npm install @dzhonragon/4less
```

## Quick Example

```
div.card {
  h1 "Hello, 4less"
  p "A minimal DSL for HTML."
  a "Learn more" href:"https://github.com/dzhonragon/4less"
}
```

Compile it:

```bash
npx 4less index.4l
```
